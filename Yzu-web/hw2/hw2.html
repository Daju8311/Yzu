相同的頁面，不同的樣式表

這是一個極具視覺效果的動態展示，呈現同一份 HTML 網頁結構在套用不同 CSS 樣式表時，如何徹底改變整體的視覺風格、字體排版與布局思維。

您可以點擊選單中的按鈕，或者點擊下方對應的連結來動態體驗樣式切換：
樣式表 1 (莫蘭迪風), 樣式表 2 (報紙風), 樣式表 3 (工業風), 樣式表 4 (電子風)。

每個樣式表皆獨立定義了獨特的字體階層（Typography Hierarchy）、CSS 欄位分欄、漸層光影與圓角幾何風格。

核心技術特點 (Technical Features)

  • 使用 CSS3 漸層背景：靈活運用 linear-gradient、repeating-linear-gradient 與 radial-gradient 創造視覺深度。
  • 圓角邊框與陰影效果：結合 border-radius、box-shadow 與霓虹發光 text-shadow。
  • 平滑過渡動畫：透過 CSS transition 屬性實現軟和流暢的選單 Hover 與懸浮動畫效果。
  • 140 種命名顏色：大量選用 W3C 標準命名色彩（例如 steelblue, papayawhip, sienna, springgreen, chartreuse 等）。
  • 響應式布局考量：利用 CSS Media Queries (@media) 自動適配桌機、平板與行動裝置螢幕。
