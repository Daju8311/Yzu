交通指引

• 火車：搭乘火車至內壢火車站，由後站出口步行約 10-15 分鐘即可抵達校門。

• 公車：可搭乘桃園市公車 155、156 路公車直達元智大學站。

• 自行開車：國道一號內壢交流道（中壢/大園出口）下，往中壢方向行駛並轉至遠東路。
