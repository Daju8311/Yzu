元智大學資訊工程學系網站重構與設計規範

本文件詳實記錄元智大學資訊工程學系網站改版之八大核心設計項目，涵蓋問題觀察、設計理念、色彩配置、RWD 響應式斷點、互動規格、方案比較、測試驗證與協作紀錄。

DOCUMENT DIRECTORY (8 SECTIONS)

1. 問題觀察 2. 設計理念 3. 風格與配色 4. 版型與響應式 5. 互動規格 6. 方案比較 7. 測試與修正 8. 來源與協作

01 問題觀察 (Problem Observation)

經過對現有系所官方網站與同類型大專院校系所網站的操作分析，發現傳統網頁普遍存在以下痛點：

  • 資訊架構繁雜過時：選單層級過深，使用者往往需要點擊 3 至 4 次才能找到「教室借用辦法」或「課程規劃」等關鍵資訊。
  • 視覺疲勞與缺乏鑑別度：多數官網採用傳統呆板的藍白表格，缺乏符合資訊工程與前瞻科技（AI、雲端、物聯網）特質的視覺美學。
  • 響應式斷點體驗不佳：在行動裝置（360px 寬度）瀏覽時，表格容易超出螢幕範圍，且按鈕觸控區過小，造成操作障礙。

02 設計理念 (Design Philosophy)

本專案選定 方案 B：極致未來感（Cyberpunk / Future UI） 作為官方主站核心設計理念，核心訴求如下：

  • 任務導向式資訊組織：將 8 大核心服務（系所介紹、課程、師資、研究、公告、活動、資源、聯絡）提升至首頁直覺卡片，大幅減少尋找路徑。
  • 融合資工專業語境：透過沉浸式深色模式、霓虹青藍色光暈與互動式終端機（CLI），讓造訪者第一眼即感受到資工系的數位前瞻性。
  • 兼顧美學與易用性：維持高對比文字與清晰的階層排版，確保在不同螢幕尺寸下皆具備極佳的可讀性。

03 風格與配色 (Style & Color Palette)

深色基底 (Dark Base)

使用 #070B19 作為主背景色，營造沈浸式科技感並降低長時間瀏覽的視覺疲勞。

卡片容器 (Card Surface)

使用 #1C2541 結合毛玻璃特效與細緻邊框，形塑立體分層與現代感。

霓虹強調色 (Cyber Cyan)

使用 #00D2FF 與元智藍相互映襯，用於突顯重要按鈕、圖示與互動回饋。

04 版型與響應式設計 (Layout & Responsive Design)

採用 Tailwind CSS 彈性網格系統（Flexbox / Grid），針對三種主流裝置寬度進行精準適配：

360px

行動裝置（Mobile）：單欄流動佈局，導覽列與卡片垂直堆疊，字級與間距自動縮減，確保拇指好點擊。

768px

平板電腦（Tablet）：雙欄網格排列，導覽列保持水平展開，最適化觸控與資訊檢索流暢度。

1280px

桌面寬螢幕（Desktop）：四欄式網格佈局搭配全版特效與互動終端機，提供最豐富的視覺層次。

05 互動規格 (Interactive Specifications)

本站設計了三項有目的之互動機制，滿足作業規範要求：

互動一：純 CSS 懸停浮起

目的與觸發：引導使用者視覺焦點。滑鼠懸停於 8 大功能卡片時觸發。

狀態與回饋：外框發光轉為青藍色，卡片輕微向上浮起 scale-[1.02]。

互動二：純 CSS 毛玻璃特效

目的與觸發：維持頂部導覽識別度。頁面向下滾動時觸發。

狀態與回饋：背景自動轉為半透明毛玻璃 backdrop-blur-md，兼顧內容穿透與可讀性。

互動三：命令列終端機 (CLI)

目的與觸發：提供趣味與資工特色導覽。使用者輸入指令並按下 Enter。

狀態與回饋: 即時解析指令（如 help、contact、fields）並於視窗內印出對應資訊。

06 方案比較 (Proposal Comparison)

比較項目 方案 A (極簡現代風) 方案 B (未來科技風 - 主站) 方案 C (經典學術新聞風)
視覺風格 大面積留白、淺色俐落 沉浸式深色、霓虹光暈 高對比雙欄、傳統學術
資訊組織 單欄流動卡片 四欄網格 + 互動終端機 左側固定選單 + 右側列表
選定理由 適合強調簡潔排版之情境 最契合資工系前瞻科技特質 適合傳統公文與新聞公告

07 測試與修正 (Testing & Iteration)

7.1 平板 768px 與裝置斷點測試

針對選定主站（方案 B）進行 768px 平板尺寸測試時，發現頂部導覽列項目過多導致換行擁擠。已透過 CSS 媒體查詢與 Flexbox 彈性間距修正，確保在平板尺寸下選單排列整齊、字級適中。

7.2 同學實際查找與互動測試紀錄

• 陳同學（大一資工系）測試紀錄：實際於 768px 平板模式下查找「教室借用辦法」，透過資源頁面順利於 3.5 秒內完成，回饋指出深色科技風介面流暢、無視覺壓迫感。
• 林同學（大一資工系）測試紀錄：測試互動終端機輸入 fields 指令，即時查詢五大研究領域。回饋表示命令列互動非常有資工系特色，點擊體驗直覺。
