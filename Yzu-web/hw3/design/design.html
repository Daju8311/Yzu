方案 A：極簡現代風

資訊組織：採左右雙欄對稱排版，資訊極度精簡，強調留白。

視覺層級：以大標題與乾淨卡片襯托，適合喜歡純粹閱讀的使用者。

色彩角色：白底灰階搭配溫和的 YZU 藍，呈現高冷洗鍊感。

方案 B：賽博未來風 已選定

資訊組織：模組化非對稱網格，首頁直接呈現四大前瞻研究領域與動態公告。

視覺層級：以強烈對比的 Dark UI、霓虹青色點綴與微互動提升視覺焦點。

色彩角色：深邃夜空黑搭配未來電光青（#00D2FF），完美呼應資工科技感。

方案 C：經典學術風

資訊組織：三欄式傳統學院門戶佈局，兼顧各類公告與連結。

視覺層級：強調嚴謹公務感，以實線框線區隔資訊區塊。

色彩角色：以大面積傳統深藍色為主，營造穩重嚴格的學術氛圍。

互動一：研究領域卡片動態懸停 (純 HTML + CSS)

目的：引導使用者探索四大研究方向並提供點擊暗示。

觸發與狀態：滑鼠懸停 (`:hover`) 觸發；卡片向上浮動 6px，外框轉為亮青色（#00D2FF），並伴隨微光陰影。

互動二：頂端導覽列毛玻璃動態固定 (純 HTML + CSS)

目的：讓使用者在長頁面滾動時，隨時能夠快速切換至其他子頁面。

觸發與狀態：頁面向下滾動時觸發；導覽列維持固定（`sticky top-0`）並套用背景模糊（`backdrop-blur-md`）。

互動三：公告區塊動態互動與檢視 (JS / 響應式點擊)

目的：快速切換與預覽最新學術活動與系所公告。

觸發與狀態：點擊列表項目觸發；動態展開詳細說明或跳轉至對應子頁面。
